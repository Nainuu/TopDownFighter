# 🔫 Top-Down Fighter Game
https://husnain-anwar.itch.io/top-down-fighter

A fast-paced 2D top-down shooter built in Unity as part of my unity journey which started a month ago.
clear rooms by eliminating enimeies to unlocks the next part of the game until you find the boss enemy! 
My 3rd unity project which was created as a learning project to explore Unity's **scene management**, **Input System**, and  **game architecture**.

## 🎮 Features

- Smooth top-down movement and shooting
- Dynamic enemy spawns and room system
- Health and damage system for both player and enemies
- Gain health by killing enemies
- Multiple scenes with proper transitions
- Input System (Unity's new Input System)
- Modular and scalable game structure
- Animations and hover effects

## 🛠️ Built With

- **Unity**
- **C#**
- Unity’s **New Input System**
- Scene Management
- ScriptableObject architecture (if used)
- Custom UI for health, pause, and settings
- Dotween for animations
